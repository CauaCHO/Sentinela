# Decisões do Projeto

## Direção

O Sentinela será desenvolvido como um sistema de memória operacional para uso transparente e autorizado.

## Regra importante

Qualquer captura de fala deve ter ciência das pessoas envolvidas, indicador visível de funcionamento e controle de acesso aos registros.

## Arquitetura

- API central em Node.js
- Painel em React
- Listener local separado
- Banco PostgreSQL
- IA local com Ollama
- Transcrição local no futuro
